# Key Concepts

<p class="meta"><span class="badge">For revision</span><span class="badge">Grows every week</span><span class="badge badge--accent"><!-- kc:count all --> concepts so far</span></p>

Every idea from the lectures, one card each: what it means in a sentence or two, what it looks like in our bank, and what it is most often confused with. Each module starts with a map of how its ideas connect, because most exam questions are about two ideas at once.

New cards appear here in the same week as their lecture.

## How to use these pages

<ol class="kc-steps">
<li><strong>Start with the map.</strong>Follow the arrows and say each one as a sentence: a class describes objects, a reference points at an object.</li>
<li><strong>Read the cards.</strong>Read each definition, then the code under it. Find that code in the lecture repository.</li>
<li><strong>Test yourself.</strong>Switch to Test yourself. Explain each term out loud before you turn the card. Reading a definition again feels like learning; recalling it is what makes it stay.</li>
<li><strong>Check the pairs.</strong>Most mistakes come from mixing up two similar ideas. The commonly confused page sets them side by side.</li>
</ol>
